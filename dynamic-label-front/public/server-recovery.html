Server QR Recovery Demo

This isolated page sends one image at a time to the existing scanner API. Recovery runs on the server. It does not confirm a scan, create an order, change inventory, make a payment, or open a returned link.

Camera access requires HTTPS (or localhost) and browser permission. The preview image is reduced to at most 960 pixels wide and sent as JPEG at quality 0.72, matching the existing scanner capture. Image uploads are sent unchanged.
